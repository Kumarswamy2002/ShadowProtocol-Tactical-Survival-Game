# Contributing to Shadow Protocol

Thank you for contributing to Shadow Protocol!

## 1. Code Standards
- Adhere to `.editorconfig` rules across C# and Python.
- Maintain high unit test coverage for new gameplay features and backend APIs.
- Keep core domain models decoupled from Unity MonoBehaviours.

## 2. Submitting Pull Requests
1. Fork and create a branch from `develop`.
2. Commit your changes following conventional commit syntax (`feat:`, `fix:`, `test:`, `refactor:`).
3. Ensure automated tests pass locally before opening a pull request.
4. Fill out the PR template in `.github/pull_request_template.md`.
